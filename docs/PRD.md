# Grimoire — Product Requirements (plan of record v0.1, 29 Aug 2026)

**One sentence.** Grimoire is a 5E-compatible *player companion* for the Light Phone 3: the
mutable half of a paper character sheet (hit points, slots, uses, conditions, coin), one-tap
dice for the rolls you make every round, the SRD 5.1 rules text you keep having to look up,
and a session journal you can fill in with the scroll wheel — offline, finite, no account.

**Who it is for.** A player at a physical table who keeps a paper sheet (Tyler's table today).
The paper sheet stays the source of truth for the *static* character; the phone owns what
pencil-and-eraser handle badly and what the book handles slowly.

**Category (Tool Library lens).** Reference + tracker + game aid. Offline, `permissions = []`,
finite by construction: a character has a fixed number of things to track, the compendium is
a fixed 2.6 MB, a session log ends when the session ends. Nothing refreshes, nothing pushes,
nothing is infinite. Nearest banned categories: none. Full one-pager: `docs/VETTING-DEFENSE.md`.

## 1. Principles

1. **Never ask for the keyboard at the table.** Every in-play action is a tap or a wheel turn.
   Text entry exists only when creating things (names) and is single-line.
2. **State, not prose.** Non-SRD features (a Battle Master's manoeuvres, a homebrew item) are
   tracked as *named counters* and *named attacks*; their rules text lives on paper. The tool
   ships only SRD 5.1 text and never asks the player to type rules in.
3. **The wheel has a job on every screen.** Scroll lists, nudge numbers, step exhaustion.
   (Hardware wheel events reach tools as key codes 317/318/319 — verify on device in M0.)
4. **Weight and glyph, never hue.** Three theme tokens; bloodied is heavier type, a spent pip
   is hollow, an expired concentration is struck through.
5. **Finite and calm.** No streaks, no stats, no "roll history" beyond the last ten rolls, no
   notifications, no network. Settings stay near-empty.
6. **Rules math is an oracle, not an opinion.** The Kotlin engine replays `fixtures/*.json`
   generated by the Python reference; a rules question is settled in `pipeline/reference/`
   first.

## 2. Evidence this is worth building (from `docs/research/`)

- Zero TTRPG, dice, or character-sheet tools exist on the LP3 (awesome-light: 0 of 73;
  GitHub topics; org discussions). Passatempo has a generic dice mini-game only.
- Every mainstream sheet (D&D Beyond, Roll20 2024, Foundry, Fantasy Grounds, Fight Club 5e)
  converged on one IA — vitals header + Actions/Spells/Inventory/Features tabs — and the
  loudest unmet request is a *combat mode*: "a big list of my actions and a big list of my
  spells" with resource spends adjacent. Roll20 retired its mobile app (Feb 2026); D&D Beyond
  is building an in-person companion for 2027.
- What players do per 4-hour session, ranked: attack+damage (10–30×) › HP change (10–20) ›
  read a spell/feature (5–15) › skill check (5–15) › slot spend (5–15) › save (3–10) ›
  feature counter (3–10) › condition/concentration (2–8) › rest (1–3) › inspiration ›
  death saves. Level-up and inventory are out-of-session.
- Two primitives cover nearly all in-play state: `counter{value,max,reset}` and a
  Roll20-style `roll{formula,label,adv}`. HP is best stored as *max + damage taken + temp*.
- Player journals reduce to who/where/quest/loot/session with one link primitive; capture is
  fragmentary live and cleaned up on a laptop later (a 337-comment DM-side sample ran 93:9
  "write after" vs "pause to write"; player guides describe the same two-pass habit).
- SRD 5.1 is completely available as CC-BY-4.0 structured data (5e-bits, Open5e); attribution
  is one fixed sentence; the tool must not use "D&D"/"Dungeons & Dragons" in its identity.

### v1.x candidates (decide after device testing)

- QR export of a character / journal as chunked QR pages (zxing is allow-listed; no
  permission needed to *show* a QR) and QR import (needs `CAMERA`).
- Quick build (five picks from SRD content with smart defaults) as an alternative to transcribe.
- Level-up assistant (bump level → HP max suggestion → new SRD features → counters).
- Voice memo on a journal entry (`RECORD_AUDIO`, `LightAudio` recorder) — transcribe off-device.
- 2024 rules pack (SRD 5.2.1) as a second edition — schema already carries `edition`.

### Non-goals (deliberate)

Full character builder, multiclass wizardry, homebrew editors, inventory weight/containers,
party inventory, maps, 3D dice, art/portraits, DM tools (initiative, encounters), any
network feature, accounts, sync, notifications, colour.

## 4. Hard constraints (verified against `light-sdk` @ `3df3c24`, 25 Aug 2026)

- Assets must be `.json/.txt/.md/.bin/...` ≤ 5 MiB each (builder `allowlist.py`) → compendium
  ships as JSON chunks, imported into Room on first launch (index hash in DataStore).
- No `Context`, clipboard, share sheet, file picker, notifications, exact alarms, custom haptics.
- Text entry is the full-screen `LightTextInputEditor`; `LightTextField` is display-only.
- `sdk:ui` has no toggle/stepper/tabs/dialog-with-content; build them from `LightText` +
  `lightClickable` + glyphs (`TOGGLE_STATE_ON/OFF`, `SELECT_ON/OFF`, `CIRCLE`, `STAR`).
- Nav stack and view models are in-memory only: every screen rebuilds from Room/DataStore.
- `permissions = []`, no `capabilities` declared, `orientation = "portrait"`.

## 5. Success criteria

- A level-5 cleric on paper is transcribed in under 4 minutes with ≤ 2 keyboard trips.
- Attack+damage, HP change, spell cast, and condition toggle are each **one tap** from the
  sheet hub, never more than two.
- Reading any spell's text from the Turn screen ≤ 2 taps.
- Kill the process mid-rest and relaunch: nothing lost (debounced, NonCancellable saves).
- `./gradlew :tool:testDebugUnitTest` replays every fixture green; `:tool:assembleRelease`
  passes the plugin scan and R8.
- The vetting one-pager has no open question a reviewer would raise first.

## 6. Open decisions (the user's to make)

1. **Name.** Decided: **Grimoire** (`dev.tyler.grimoire`) — ADR-0005, 28 Aug 2026. The working
   name was *Familiar*; alternatives considered: *Satchel*, *Tavern*, *Hearth*. `id` is permanent.
2. **Creatures in v1?** 334 stat blocks add 0.8 MB and serve druids/rangers/summoners. In by
   default; drop if the reviewer reads a bestiary as DM-side.
3. **Journal in v1 or v1.1?** Spec'd for v1 (P1); it is the piece with the most novel UI.
4. **Roll history at all?** Ten rolls, no stats, cleared on relaunch — or none.
5. **Wheel consumption.** Consuming wheel events disables LightOS brightness while the tool is
   open; confirm on hardware and decide whether the wheel is used everywhere or only on
   number pads.
